# Font Sources And License Declarations

The catalog records the license type declared for each submitted font. Supported labels are:

- **Commercial use allowed** (`commercial-use`)
- **Personal use only** (`personal-use`)
- **Not provided** (the `license_type` field is omitted)

These labels are supplied by contributors and are not a legal verification by this repository. Contributors are responsible for having permission to upload and redistribute submitted files. Source, author, copyright, and license links are included when they are known, but an original upstream repository or OFL license is not required.
